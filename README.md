# SimpleFTP

Windows 11 向けの、シンプルなマテリアルデザイン風 FTP クライアントです。
Python の標準ライブラリ（tkinter / ftplib）だけで動くので、追加パッケージは不要です。

## 起動

1. Python 3.10 以上をインストール（python.org 版推奨。インストール時に「Add python.exe to PATH」にチェック）
2. `run.bat` をダブルクリック（Python が無い場合はダウンロード方法が表示されます）

### exe にしたい場合

`build_exe.bat` をダブルクリックすると `dist\SimpleFTP.exe` ができます（PyInstaller を自動で入れます）。
できた exe は Python が入っていない PC でも動きます。

## できること

- FTP / FTPS（明示的 TLS）接続、文字コード（UTF-8 / Shift_JIS）切り替え
- 左が PC、右がサーバーの 2 ペイン表示。真ん中の → / ← で転送
- フォルダーごとのアップロード・ダウンロード、進捗バー、キャンセル
- 右クリック「開く」でファイルを関連付けられたアプリで開く（サーバー側は一時フォルダーにダウンロードして開くので、編集してもサーバーには反映されません）
- 新しいフォルダー・名前の変更・削除（PC 側の削除はごみ箱へ）
- 列見出しクリックで並べ替え、右クリックメニュー（このPC側は「エクスプローラーで開く」で表示中のフォルダーを開けます）

## ショートカット

| キー | 動作 |
|---|---|
| ダブルクリック / Enter | フォルダーを開く・ファイルを転送 |
| Backspace | 上のフォルダーへ |
| F5 | 更新 |
| F2 | 名前の変更 |
| Del | 削除 |
| Ctrl+A | すべて選択 |

## メモ

- ホスト・ポート・ユーザー名・パスワード・左側（このPC）で最後に開いたフォルダーは `%APPDATA%\SimpleFTP\settings.json` に保存されます。フォルダーはそのつど保存されるので、次回もその場所から始まります（フォルダーが無くなっていたら親フォルダーを開きます）。
- パスワードは Windows の暗号化機能（DPAPI）で暗号化して保存するため、同じ PC の同じ Windows ユーザーでしか読み出せません。保存したくない場合は「パスワード保存」スイッチをオフにしてください（保存済みのものも消えます）。
- ホスト欄に `ftps://example.com` と入れると FTPS が自動で ON になります。
- 普通の FTP は通信が暗号化されません。サーバーが対応していれば FTPS を使ってください。
- パッシブモード固定です。
